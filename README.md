## 📖 Overview

A responsive college portal prototype developed for **Vidya Prasarak Mandal's Polytechnic, Thane**. This project demonstrates core **Responsive Web Design (RWD)** fundamentals using pure semantic HTML5 and custom CSS3 responsive grid architecture, built completely from scratch without external CSS frameworks.

---

## ✨ Key Features

- **📐 Custom 12-Column Grid System:** Built using proportional percentage-based column widths (`col-1` through `col-12`).
- **📱 Fluid Multi-Device Breakpoints:**
  - **Mobile (< 600px):** Single-column stacked layout with full-width cards.
  - **Tablets (600px - 768px):** Semi-compact multi-column grid (`col-s-*`).
  - **Desktop (> 768px):** Full desktop three-column container with navigation, hero content, and departmental sidebar.
- **🎨 Pure CSS Styling:** Smooth hover effects, box shadows, and modern card typography.
- **⚡ Lightweight & Fast:** Zero external library dependencies, instantaneous page loading.
